# 决策支持内容模块技术说明（防灾实例 / 工程措施 / 非工程措施）

> 本文档说明"青藏高原冰冻圈灾害数字孪生系统"决策支持模块下**防灾实例、工程措施、非工程措施**三个子功能的设计、内容与资料来源。更新日期：2026-08-28。

## 1. 模块定位

三个子功能与"决策支持智能体""院士专家名录"并列，构成决策支持模块的完整知识体系：

| 功能 | 定位 |
| --- | --- |
| 防灾实例 | 青藏高原及同类冰冻圈灾害的**真实案例库**（成因机制 / 过程影响 / 处置经验 / 对本系统研究区的启示） |
| 工程措施 | 防洪、泥石流防治、滑坡与堰塞湖、冰湖防治、冻土工程、雪害防治六类**工程手段**（原理 / 适用场景 / 真实工程实例） |
| 非工程措施 | 监测预警、应急预案、群测群防、宣传教育、风险管理、保险救助六类**管理手段**（做法 / 要点 / 适用） |

内容全部基于**公开权威资料**（政府通报、权威媒体报道、学术文献、行业规范、单位官网），机制描述真实可靠，每条记录标注资料来源。

## 3. 与系统其他模块的关联

- **灾害库对应**：案例与本系统灾害类型一一对应——GLOFs（冰湖溃决145例）、LLOFs（滑坡堰塞湖43例）、PFs（降雨洪水94例）、SFs（融雪洪水38例）、RTS（热融滑塌2669例）、雪崩（44例）、风吹雪（62例）；
- **阈值与预警**：非工程措施"阈值预警"直接引用本系统 grid_threshold_10p-99p 百分位阈值场；
- **风险评估**："风险普查与区划""危险区划定"与本系统 R=H×E×V 风险评估（五级分级）衔接；
- **专家名录**：冻土工程案例对应专家名录中程国栋院士（冻土学）研究领域。

## 4. API 与前端

- 接口：`GET /api/decision/content`（返回 cases / engineering / non_engineering 及计数）
- 后端：`webgis_backend/modules/decision.py`（蓝图已注册于 app.py）
- 前端：decision.html 三个侧边栏（`#prevention-example-category-sidebar` / `#engineering-category-sidebar` / `#non-engineering-category-sidebar`），由 `webgis_frontend/js/decision-content.js` 渲染，交互为「**关键词搜索框 + 卡片列表 + 点击展开详情**」（顶部分类筛选 chips 已移除；每个侧边栏顶部新增与专家名录同款的搜索框 `#case-search-input` / `#eng-search-input` / `#ne-search-input`，搜索覆盖 标题 / 类型(category) / 标签(tags) / 详情文本，卡片保留分类标签与类型标签），与本系统深色科技风及专家名录交互一致。

## 5. 科研规范与可靠性

1. **机制真实**：灾害成因与工程原理均依据公开学术文献、行业规范与权威报道撰写，不使用虚构案例；
2. **数据可溯源**：每条记录 source 字段标注资料来源（含链接），可逐条核对；
3. **表述严谨**：不确定的数字采用"量级/据公开报道/研究报道"等限定表述，避免夸大；
4. **贴合研究区**：案例与措施优先选取青藏高原及周边（西藏、川西、甘肃、新疆南部）真实事件，与本系统研究区一致。

## 6. 已知边界与后续规划

- 案例库与措施库可通过编辑 `decision_content.json` 持续扩充（如增加具体冰湖名录、更多工程实例）；
- 可进一步为案例关联本系统 GIS 图层（灾害点定位到地图）与模拟结果，实现"案例-数据-模拟"联动；
- 可增加案例时间轴、地域分布统计等可视化。
