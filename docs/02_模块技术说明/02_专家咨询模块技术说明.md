# 院士专家名录模块技术说明

> 本文档说明"青藏高原冰冻圈灾害数字孪生系统"决策支持模块下**专家咨询（院士专家名录）**功能的设计、数据来源与科研规范。更新日期：2026-08-28。

## 1. 模块定位

专家咨询与"决策支持智能体"（`/api/llm/chat`）为决策支持模块下**同级别的两个功能**，但定位不同：

| 功能 | 决策支持智能体 | 专家咨询（院士专家名录） |
| --- | --- | --- |
| 定位 | AI 对话问答（机理分析、决策建议） | **专家资源名录**：找专家、看简介、联系单位 |
| 内容 | 大模型生成回答 | 院士**公开学术资料**整理的名录档案 |
| 联系方式 | 无 | 专家所在单位**公开联系方式**（单位/地址/电话/官网） |
| 检索 | 自由对话 | 关键词搜索（姓名 / 领域 / 单位 / 简介 / 标签，如"冰川""积雪""冻土""融雪洪水"均可命中） |

设计依据：参照应急管理/水利行业《专家库管理办法》的通行做法（如河南、广州等地应急管理专家库管理办法，以及安徽省水旱灾害抢险专家系统）——专家库的本质是"名录 + 简介 + 领域分类 + 联系方式 + 管理维护"，用于应急会商、现场处置时按领域**检索专家并联系**；而非用 AI 模拟专家作答（后者属于决策智能体职能，已独立存在，避免功能重复）。

## 2. 数据来源与字段

| 字段 | 说明 |
| --- | --- |
| name / title | 姓名、头衔（院士为"中国科学院院士 · 职务"形式，不附当选年份；研究员附主要学术荣誉） |

| field | 研究领域（多关键词） |

## 3. 功能与 API

| 功能 | 接口 | 说明 |
| --- | --- | --- |
| 名录列表 | GET /api/expert/profiles | 全部专家（含简介与联系方式、tags 标签），支持 `?field=` 领域筛选、`?q=` 关键词搜索（含 tags） |
| 领域分类 | GET /api/expert/fields | 专业领域分类（保留接口；前端已不再渲染"领域"筛选 chips，标签改由搜索框检索） |

前端（decision.html → 决策支持 → 专家咨询）：
- 免责声明（公开资料整理、不展示个人联系方式）；
- 关键词搜索框（姓名 / 领域 / 单位 / 简介 / 标签，如"冰川""积雪""冻土"均可命中）；
- 专家名片多标签展示（各类冰冻圈灾害 + 研究方向），**不再提供"领域"分类筛选 chips**（一位专家往往横跨多个方向，单分类会遗漏）；
- 名录卡片：点击展开详情（学术简介、代表成果、核心观点、论文著作、单位联系方式、信息来源 URL）。

## 4. 科研规范

1. **信息真实可溯源**：所有档案基于公开学术资料（sources 字段记录来源 URL，可逐条核对）；不确定的信息不编造。
2. **联系方式合规**：仅公开单位渠道，不展示个人私密联系方式，符合科研伦理与个人隐私保护要求。
3. **边界清晰**：名录展示专家资源与联系方式，不替代 AI 决策咨询（决策智能体承担问答职能），模块职责不重复。
4. **可维护**：档案为独立 JSON 文件，管理端"数据管理"页展示名录状态，可直接编辑维护。

## 5. 已知边界与后续规划

- 当前收录 10 位专家（6 位院士 + 3 位本实验室一线研究员 + 1 位研究所所长级研究员）；可参照应急管理专家库的"专业领域分类表"继续扩充科研/工程一线专家（需逐位核实公开资料）；
- 名录维护暂为 JSON 文件编辑；后续可在管理端提供专家档案的增删改界面（申报-审核-入库流程），对齐《专家库管理办法》的完整管理闭环；
- 单位联系方式以官网公开信息为准，如单位电话/地址变更需定期复核更新。
